Example messages from the Bacen SPI message catalog, version 5.13.1
(`https://www.bcb.gov.br/content/estabilidadefinanceira/cedsfn/Catalogos/spi.5.13.1.zip`, folder `exemplos/`),
copied unchanged, together with its schemas (`xsd/` → `xsd-5.13.1/`). They are the reference for the parser and the routing table: when Bacen publishes a new
catalog, add its examples next to these and run `SpiCatalogTests`.
